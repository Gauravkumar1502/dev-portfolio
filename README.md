# dev-portfolio

My developer portfolio in two modes: a neobrutalist **GUI** and an interactive **terminal** you
can type into. Switch with the `>_ terminal` button in the GUI, or type `gui` in the terminal.

**Live:** https://gauravkumar1502.github.io/dev-portfolio/
